# ROM FLOW

Fluxo de despesas corporativo do Grupo ROM: solicitações, aprovações, pagamentos, governança e auditoria.

Empresas do grupo:

- Baru Bistro Brasil
- Baru Bistro Iguatemi
- Rom Academy
- Rom Concept Brasil
- Rom Concept Iguatemi

## Scripts

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000). No primeiro acesso, cadastre o administrador do grupo. Os dados ficam no `localStorage` do navegador.
